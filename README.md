# 📦 Recursos para la Práctica – Mi Web

Bienvenido/a 👋  

Este repositorio contiene los **recursos oficiales** que necesitarás para desarrollar tu práctica del proyecto **"Mi Web"**.

Aquí encontrarás imágenes, archivos base y material necesario para completar correctamente los ejercicios.

## 🚀 ¿Qué contiene este repositorio?

Dentro de este proyecto encontrarás:

- 🖼️ Carpeta de imágenes optimizadas
- 📁 Archivos base para la práctica
- 🎨 Recursos gráficos
- 📄 Material complementario

Estos recursos deben ser utilizados durante el desarrollo del proyecto en clase.

## 📥 ¿Cómo descargar los recursos?

Sigue estos pasos:

### 🔹 Opción 1: Descargar como ZIP (Recomendado)

1. Haz clic en el botón verde **Code**
2. Selecciona **Download ZIP**
3. Extrae el archivo en tu computadora
4. Coloca la carpeta dentro de tu proyecto

### 🔹 Opción 2: Clonar con Git

Si ya tienes Git instalado, puedes ejecutar:

```bash
git clone https://github.com/alexroel/mi-web-recursos.git
````

Luego ingresa a la carpeta:

```bash
cd mi-web-recursos
```

## 📂 ¿Dónde colocar los archivos?

Se recomienda la siguiente estructura dentro de tu proyecto:

```
mi-proyecto/
│
├── index.html
├── audio/
├── images/
└── video/
```

Puedes mover los recursos descargadas a la carpeta del proeyecto`mi-web/`.


## 🎯 Objetivo de la práctica

El objetivo es que aprendas a:

* Organizar correctamente los recursos de un proyecto web
* Trabajar con rutas relativas
* Integrar imágenes y archivos externos en HTML
* Mantener una estructura profesional de carpetas
